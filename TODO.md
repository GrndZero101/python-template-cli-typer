# TODO

This repo's work is tracked in [python-template-base](../python-template-base)'s `tp` store, one
store for the base, this repo and the canary. Tasks for this repo are tagged `cli`:

```bash
tp --root ../python-template-base list --tag cli
TP_ROOT=../python-template-base tp next
```

The board is that repo's `TODO.md`, generated by `tp`. A field finding from a generated project —
an enhancement found while building it, naming the working code to copy — becomes a task there,
tagged by the layer it touches, with `--meta source=<project>`:

```bash
tp --root ../python-template-base add "<finding>" --tag cli --meta source=<project> --desc "..."
```
